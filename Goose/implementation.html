Run Goose Patrol

Use Java 17 with a desktop display. Run the command for your operating system from the directory containing the JAR.

Windows or Linux
java -jar Goose-Patrol.jar
macOS
java -XstartOnFirstThread -jar Goose-Patrol.jar

Press Enter to start. Use the arrow keys to move and Left Shift to run. Press F when the goose is nearby, I or J to add a potion, and 1–3 to use an inventory slot.

Source guide

Files in the supplied source snapshot.

core/
Game logic. Main coordinates the game loop, Input handles key input and secret inputs, and Player and Inventory handle item effects and quantities. Goose follows the player and can be deactivated at close range.
lwjgl3/
Desktop launcher and Gradle packaging configuration.
assets/
Game textures, item sprites and character artwork, with attribution files for the player artwork.
